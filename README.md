# 东晟 AI 健康管家

独立的健康与体重管理问答服务，包含文字问答、短会话记忆、舌照/体测图片解读和受控产品推荐。项目不属于黄雀主站或黄雀小程序。

## 能力

- 文字健康问答与两小时进程内短会话
- 舌照可见特征、体测报告和普通图片解读
- 按用户实际问题匹配受控产品资料
- 过敏、孕哺、儿童、用药、重大慢病和急症安全拦截
- 模型故障时返回本地安全兜底，不暴露上游错误

## 本地运行

需要通过环境变量提供 OpenAI 兼容接口配置，真实密钥不得提交到仓库：

```bash
export OPENAI_API_KEY="..."
export OPENAI_BASE="https://example.com/v1"
python3 hqbot_api.py
```

服务默认监听 `127.0.0.1:8093`：

- `GET /health`
- `POST /api/chat`
- `POST /api/tongue`

## 验证

```bash
OPENAI_API_KEY=test \
OPENAI_BASE=https://example.com/openai/v1 \
python3 test_hqbot_api.py
```

## 安全边界

本项目提供日常健康与营养信息，不做疾病诊断、处方或治疗承诺。产品成分与支持方向来自企业资料，实际配料、过敏原和食用要求以包装标签及专业人员意见为准。

仓库不包含生产密钥、密码、用户健康数据、价格、库存或订单信息。
